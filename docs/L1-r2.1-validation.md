## Implementation

`l1_perception.h` declares the frozen API and exact enums.
`l1_perception.c` implements the preregistered ordering:

1. unknown quality is normalized to `INVALID/UNRELIABLE`;
2. `ABSENT` is `UNKNOWN`;
3. invalid, stale, regressed and reset quality is `UNRELIABLE`;
4. invalid or out-of-range observations normalize to
   `INVALID/UNRELIABLE`;
5. otherwise the fixed 3000/100/500 bp boundaries produce the frozen eight-
   mask state table.

The module has no mutable global/static state, heap, clock, file, network,
kernel or device interface. It accepts no core, policy or action. The existing
source audit now rejects those interfaces in the classifier.

## Deterministic test coverage

The assertion mechanism exits explicitly and remains active with `NDEBUG`.
Normal, NDEBUG and ASan/UBSan/leak builds passed:

- all masks `0x00` through `0x07` and their exact state mapping;
- zero, below/equal/above boundaries independently for CPU, memory and I/O;
- 10,000 accepted and 10,001 rejected independently for every channel;
- invalid observation flag;
- all six quality values plus `-1`, `6` and `127` unknown values;
- absent input ignoring unusable fields, preservation of recognized failure
  quality and normalization of malformed quality/input;
- 1,000 repeated classifications per case with identical member results and
  unchanged input bytes;
- a ten-row mixed core replay covering CPU, I/O, memory overlap, invalid
  telemetry, external stale/reset/absent metadata and regressed core time.

For every replay row, the perception-enabled and observer-off core returned
the same `L1Action`, and all 104 bytes of `L1Core` were identical. External
quality metadata never entered `l1_step_at()`; the legacy timestamp regression
itself exercised the existing HOLD fallback. RC0 independently reconfirmed the
104-byte core, 208-byte shadow and 72-byte V2 state invariants.

## Frozen resource measurement

Command:

    make perception-bench

Five optimized repetitions each classified 10,000,000 deterministic samples.
The `volatile` sink prevents dead-code elimination. Separately, 50,000 calls
were individually bracketed by `CLOCK_PROCESS_CPUTIME_ID`; their sorted sample
distribution supplies a genuine empirical p95 rather than a quantile of five
run averages.

| Measurement | Result | Frozen limit | Gate |
|---|---:|---:|---|
| throughput CPU minimum | 19.855 ns/call | informative | — |
| throughput CPU median | 22.843 ns/call | <=1,000 ns/call | PASS |
| throughput CPU maximum | 26.308 ns/call | informative | — |
| individual-call CPU p95 | 4,300 ns | <=5,000 ns | PASS |
| optimized process peak RSS | 2,500 KiB | <=8,192 KiB | PASS |
| returned result | 12 bytes on this ABI | informative | — |
| persistent classifier state | 0 bytes | stateless | PASS |

The individual p95 includes two process-CPU clock reads per measured call, so
it is conservative for the classifier but sensitive to timer implementation,
virtualization and scheduling. RSS includes the whole benchmark process and
its bounded 50,000-entry timing array; it is not embedded classifier state.
No p95 is inferred from the five throughput averages.

## Limitations

- The caller supplies quality metadata; one stateless observation cannot prove
  absence, staleness, clock regression or counter reset.
- PSI stall percentages are not CPU utilization, physical memory use, health,
  fault, causation or user intent.
- `QUIET` is only below the three frozen descriptive boundaries.
- The fixed boundaries intentionally ignore current policy generations,
  hysteresis, confirmation and core history, so description and advisory
  action may legitimately differ.
- The eight-mask corpus is a known-answer test, not held-out learning evidence.
- There is no novelty, anomaly memory, learned baseline, confidence,
  individuality, forecast or action coupling.
- Synthetic correctness and microbenchmark success cannot establish real
  workload utility, resource savings or generalized intelligence.
