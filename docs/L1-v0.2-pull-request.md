## Safety boundary

This change adds no L2/L3 implementation and no actuator. It does not write
scheduler, cgroup, kernel, firmware, hardware, QEMU, or host settings. Rollback
uses only the previous validated process-local policy snapshot and requires a
new increasing generation.

## Review notes

The benchmark establishes controller overhead only. It does not establish a
throughput, latency, energy, scheduling, or resource-management benefit. Do not
merge until the recorded guest commands and results have been reviewed. Live
ranges overlap, runs were sequential and unrandomized, guest-wide PSI changed
between runs, and live decisions remained `HOLD`; synthetic traces—not the live
benchmark—exercise transitions. Policy files are not authenticated, and policy,
rollback, and adaptation state remain process-local and non-durable.
