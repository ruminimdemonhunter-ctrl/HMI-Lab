**INITIAL BRANCH COMMIT. DESIGN/CONTRACT BEFORE TEST UTILITIES OR FIXTURES. NO HELDOUT STUDY EXECUTION.**

- Parent merged V0.2 blueprint PR #38 `d9d06fbbc8fa7e005bdb8cdc5deb8c03ae932f14`; accepted V0.1 840B L2 core and fixture manifest remain protected.
- [Issue #39](https://github.com/ruminimdemonhunter-ctrl/HMI-Lab/issues/39); new branch `feature/l2-v0.2a-preflight`.
- Purpose: validate the **scientific instrument** for evaluating virtual-workspace role-triple suggestions, rather than another experiment that risks mistaking synthetic A/B divergence for meaningful utility.
- This contract governs V0.2a test-only preflight; future V0.2 full-study population, scenario probabilities, thresholds and utility weights require their own **future frozen protocol** before generator/model/data. Passing this preflight is **NOT** scientific utility GO.

## 1. Scope and outcomes

**Accepted V0.1 is fixed**: same source and ABI, `L2State` 840B on qualified guest, read-only C11 library in this phase. Allowed observations: versioned simulated time/sequence, quality, coarse role events, 4 opaque workspaces, safe context descriptors. Candidate output: one of NONE, CANDIDATE(triple), BLOCKED. Do **not** copy hidden upcoming task into model input or assume any occupational labels.

Preflight must demonstrate:
1. Independent future-task truth and authorized pre-query history remain physically/logically separate.
2. Eligibility/support are computed **post-fault and post-reset** from the real V0.1 state engine and an independently implemented verifier.
3. Baselines use identical information and output space, and a powerful baseline is not excluded when it wins.
4. Scorer rejects corrupted data, leaked labels, unmatched IDs, safety violations and misleading episode counts.
5. A SHA256-bound lock binds actual files/settings/selection before **any heldout path is opened**.
6. L1/L2 protected behavior and no-actuation authority persist, resource use remains bounded.

## 2. Required minimal test-only data contracts

**Permitted input**: strictly existing `HMI_L2_EVENT_V1` synthetic CSV grammar for recorded past episodes; no new model information, untrusted text or actual app/process/file data. Use small test-only streams, keep timestamps monotonic, and group role histories by completed SESSION_BEGIN/END in a single workspace.

**Truth file separate from histories**: deterministic, ASCII, exact field grammar declared and frozen by the eventual fixture generator; at minimum `episode_id,device_id,workspace_id,regime,allowed_query_index,truth_r1,truth_r2,truth_r3,truth_quality,safety_guard`, canonical enums and bounded row counts. Device/episode names are scorer-only metadata, **not candidate input**. The permitted history contains events occurring *before* that query. The future task triple is never encoded in an observable event, file name accessible to candidates or pre-query model field.

**Predictions file**: `episode_id,candidate_id,status,r1,r2,r3,reason` with exactly **one result per episode per candidate**. Refuse missing/duplicate IDs, unknown candidate or enum, roles attached to NONE/BLOCKED, fabricated unsupported reference, and any extra row. The independent scorer verifies join by ID, strict byte-valid grammar, query eligibility and the listed safety and truth fields.

**Pairing rule:** compare candidates on the **same episode IDs with same eligible pre-query event bytes**; no candidate gets disjoint favorable cases, future labels or device tags as features. One independent session-episode supplies one score, no per-row sample inflation. Reused/overlapping windows of the same latent next task share an episode ID and cannot be counted as independent strict wins.

## 3. Known-answer loss ONLY for test-unit verification

The following **toy loss** is frozen for checking scorer arithmetic, **NOT** a final V0.2 scientific loss or evidence of usefulness:
- Safe episode with `truth_quality=DETERMINATE`: CANDIDATE incurs **2 loss units per wrong role position** (exact 0, one mismatch 2, two mismatches 4, three mismatches 6); NONE incurs **1**; BLOCKED incurs **3** (false block).
- Safe episode with `truth_quality=AMBIGUOUS`: NONE incurs **0**; any CANDIDATE incurs **2**, and BLOCKED incurs **3**. Intent ambiguity is predeclared from independent simulator truth, not inferred from model outcome.
- `safety_guard=DENY` or `RESOURCE_PRESSURE` or `INVALID_SOURCE`: only BLOCKED (or explicitly allowed NONE for invalid-source per frozen fixture) is valid; **any CANDIDATE is a critical safety violation and causes test FAIL even if other episodes earn low loss**. No averaging away violations. On permitted safe states, BLOCKED incurs the above cost.
- No unknown truth or missing label is ever turned into a scored negative; fail invalid episode. No negative loss values, no posthoc adjustment.
- Model output "reason" must match its status and be source-supported; arbitrary explanatory prose does not satisfy a rule.

Required arithmetic fixtures: exact triple 0, single mismatch 2, double mismatch 4, triple mismatch 6, safe abstain 1, ambiguous abstain 0, ambiguous CANDIDATE 2, safe false BLOCKED 3 and unsafe candidate mandatory FAIL. Scores are integers with overflow-safe sums. These values are **not** to be copied automatically into a future science study; that requires a new explicit numerical protocol.

## 4. Baseline selection known-answer preflight

Candidates (run against identical offline histories, quality and permission rules):
- `V01_FROZEN`: accepted V0.1 source and behavior, unmodified, treated as a separately reported research candidate.
- `RECENT_N`: last **N eligible completed sessions in requested workspace**, with N in **{1,2,3,5,8}**; count contiguous role triples, choose most frequent; tie: lexicographically lowest role tuple. No lifetime learning beyond N. An unsupported/cold/stale/invalid query abstains to exactly the same safety/eligibility boundary as V0.1; N=1 may be allowed as a comparator but **not** violate shared support requirements.
- `STATIC_WORKSPACE`: most frequent complete-session role triple for workspace from designated *training* only, fixed thereafter; no update on calibration or query. Tie lexicographically.
- `STATIC_GLOBAL`: similarly trained all-workspace static triple; no device occupation label.
- `ALWAYS_NONE`: safe abstain; still honor mandatory common BLOCKED guard conditions.

Shared safety gating is an **explicit independent wrapper** with source/quality/freshness/permission guard; no model-specific bypass. Any baseline whose state or support differs is marked `INFORMATION_OR_SUPPORT_ASYMMETRY` and **may not silently be the primary fair comparator**.

**Toy calibration fixtures** must include: `RECENT_N` strictly lowest paired loss; `STATIC_WORKSPACE` strictly lowest; and `ALWAYS_NONE` strictly lowest. Select the strongest by **lowest aggregate loss**, then **lower harmful-candidate count**, then higher eligible episode coverage, then lexicographic candidate ID. Any case where selected baseline differs from the known answer **FAIL**. Grid tuning only on mock calibration episodes; deliberately corrupted selection and an invalid N value both FAIL. **Do not** use full study data, scientific heldout or actual future model thresholds in V0.2a.

## 5. Independent truth / attribution controls

- Construct a visible-history twin pair: byte-identical pre-query events, identical query/context and safety, but separate independently specified hidden next-role truth. No model can recover the difference from unavailable information; test must not award personalized intelligence for guessing. Record this as a **non-identifiability** control, not a positive utility test.
- A/B history-conditioned independent outcome truth should be separately sourced; one scorer intentionally wrong on B must fail (not merely print `truth=external`).
- At least one cold-start and one **late reset** fixture with 2 valid post-reset complete sessions, fewer than accepted V0.1's support requirements, must abstain. At least one supported fixture with >=3 completed and >=6 transitions and a triple count>=2 must produce the known permitted candidate, with fresh safe context.
- Quality INVALID/ABSENT, malformed token, duplicate session/query identity, synthetic provenance failure and `resource pressure` must not create eligible memory or unsafe CANDIDATE.
- Independent reference verifier must check actual completed sessions and role triples, not only declared metadata; test a false claimed support count and a mismatched generated "truth" row.

## 6. Integrity lock and heldout refusal test

Define **canonical, single-occurrence, strict-schema** fixture preflight lock with SHA256 of:
- accepted V0.1 `l2_state.c`, `l2_state.h`, parser and frozen fixture manifest;
- V0.2a preflight schema/fixture generator, verifier, toy scorer, each comparator source, full mock training and calibration inputs, output/selection digest;
- chosen grid N, strongest comparator ID, support/guard rules, exact schema/version and test-only scoring mode.

Recompute actual SHA256 of **all** bound files, validate each selected parameter and selection digest by deterministic rerun, reject absent/mutated/duplicate/unknown keys and reordered noncanonical byte encodings. SHA is **integrity, not authentication**.

Expose/spy on a controllable file-open boundary: when a lock is invalid, the observed number of attempts to open a fake future heldout path is **zero**. A valid *mock lock* may permit opening only a **non-study dummy sentinel fixture**, **never** a scientific V0.2 heldout file. Reject all unspecified paths and source changes.

Tampering controls: source byte, fixture CSV byte, truth byte, lock hash field, duplicate field, model ID, selected threshold/grid N, calibration digest, and fake signed-looking but wrong SHA string — all **FAIL**. Do not allow a lock created *after* first heldout opening to certify a study.
