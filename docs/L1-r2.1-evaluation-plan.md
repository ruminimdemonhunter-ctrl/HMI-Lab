# HMI L1 R2.1 — Frozen Stateless Machine-Condition Classifier Protocol

Status: **PREREGISTERED BEFORE ALGORITHM IMPLEMENTATION**. Design approved and merged in R2.0 PR #22 at main ce614abbafbbfb1380eb12166f56b5113ddd62ee. New R2.1 tracking issue #23.

This protocol is an implementation contract for Codex. It is not experimental evidence, a personal evaluation, or an authorization to control resources.

## Purpose and claim

Build a **pure C11 stateless descriptive machine-condition classifier**, reading a copy of an existing L1Observation. The classifier observes Linux PSI stall pressure; it does not infer CPU utilization, application identity, faults, user intent, health, energy, novelty, learned norms or causation.

The existing RC0 protected L1Core is the sole source of published advisory actions. New R2.1 output has NO authority to change protected action, policy, shadow, persistent state or OS settings.

## Frozen C API

Create independent src/level1/l1_perception.h and l1_perception.c. New header includes existing l1.h without modifying it.

Public enums with these exact names:
- L1PerceptionInputQuality: L1_PQ_OK, L1_PQ_ABSENT, L1_PQ_INVALID, L1_PQ_STALE, L1_PQ_REGRESSED, L1_PQ_RESET.
- L1PerceptionState: L1_PS_UNKNOWN, L1_PS_QUIET, L1_PS_CPU_PRESSURE, L1_PS_MEMORY_PRESSURE, L1_PS_IO_PRESSURE, L1_PS_MIXED_PRESSURE, L1_PS_UNRELIABLE.

L1PerceptionResult contains a L1PerceptionState state, L1PerceptionInputQuality quality, and uint8_t pressure_mask. Return an initialized result; never serialize padding. Function signature:

    L1PerceptionResult l1_perception_classify(
        L1Observation observation, L1PerceptionInputQuality quality);

No globals, no mutable static memory, no I/O, no clock, no heap, no hidden learning state. Does not accept L1Core, L1Policy or L1Action. Explicit quality metadata comes from the caller; **the stateless function cannot itself infer stale time, regressed clock, missing sample or reset from a single L1Observation**. This is an explicitly documented trust limitation until a future verified adapter exists.

Quality behavior in order:
1. An unrecognized enum quality value -> state UNRELIABLE; normalize quality to L1_PQ_INVALID; mask 0.
2. Quality ABSENT -> UNKNOWN, preserve ABSENT, mask 0 regardless of sample fields.
3. Quality INVALID, STALE, REGRESSED or RESET -> UNRELIABLE, preserve supplied quality, mask 0 regardless of sample fields.
4. Quality OK but observation.valid=false or ANY of cpu_some_bp, memory_full_bp, io_full_bp >10000 -> UNRELIABLE, normalize quality to INVALID, mask 0.
5. Otherwise quality OK; classify with immutable descriptive thresholds. All arithmetic integer and bounded.

## Exact fixed thresholds, separate from reflex policy

Thresholds are exactly the existing default policy values for **descriptive purposes only** (do not read L1Core.policy; do not apply hysteresis or confirmation):

- CPU PSI some avg10 >= 3000 bp => bit 0 (0x01).
- Memory PSI full avg10 >= 100 bp => bit 1 (0x02).
- I/O PSI full avg10 >= 500 bp => bit 2 (0x04).

Expected complete mapping:

| mask | classified state |
|---|---|
| 0x00 | L1_PS_QUIET |
| 0x01 | L1_PS_CPU_PRESSURE |
| 0x02 | L1_PS_MEMORY_PRESSURE |
| 0x04 | L1_PS_IO_PRESSURE |
| 0x03 | L1_PS_MIXED_PRESSURE |
| 0x05 | L1_PS_MIXED_PRESSURE |
| 0x06 | L1_PS_MIXED_PRESSURE |
| 0x07 | L1_PS_MIXED_PRESSURE |

Exact boundaries:
- (2999,99,499,true) -> QUIET, mask 0;
- (3000,100,500,true) -> MIXED, mask 7;
- (10000,10000,10000,true) -> MIXED, mask 7;
- (10001,0,0,true) or (0,10001,0,true) or (0,0,10001,true) -> UNRELIABLE/INVALID, mask 0;
- 0..10000 inclusive is numeric input validity, not a declaration of device health.

L1_PS_QUIET is relative to these PSI thresholds, **not** a statement the device is idle, healthy, or that protective action is unnecessary. The protected reflex and descriptive classifier may legitimately differ due to policy generations, confirmation, hysteresis and historical core state. Never erase the protected advisory.

R2.1 has **no novelty, no machine individuality, no learned baseline, no probability/confidence estimate and no 60-second forecast**. These belong to later separately evaluated stages.

## Frozen test matrix

Add independent l1_perception_test.c using failure checks that survive NDEBUG. Validate:
1. All eight mask patterns, below/equal/above threshold per channel, zero, 10000 and 10001 per channel, and invalid observation flag.
2. All six quality enum values and unrecognized quality values; metadata status preserved or normalized exactly as above.
3. Determinism for same input across repetitions; no side effects, input mutation or dependency on global/persisted state.
4. Separate ordinary protected core and observer-off reference L1Core instances replay a fixed mixed sequence covering CPU, I/O, memory, overlap, invalid sample, externally marked regressed time/reset. A copy is classified but **never** influences l1_step_at(). After every row, published L1Action and every byte of L1Core must match the observer-off reference. R2.1 test-only external quality flags do NOT covertly alter protected core fallback; regressions must be passed to the existing core timestamp parameter itself to test legacy HOLD.
5. Historic RC0 invariants 104B core, 208B shadow, 72B V2 persisted state unaffected; no change to protected source identities or historical experiment corpus/checksum.
6. Build strict C11 with compiler warnings as errors; normal, NDEBUG, ASan/UBSan/leak and RC0 smoke. Integrate into existing Makefile targets all, test and clean; maintain old rc0-ci/rc0-qualification targets and their frozen gates.
7. Standalone optimized classifier benchmark: 5 iterations, each >=10000 deterministic synthetic calls, no dead-code elimination. Report per-run min/median/max CPU ns/call and optimized process RSS. If reporting p95 **per-sample**, collect proper individual measurements or an honestly grounded quantile method; never present p95 from five per-run averages as a sample distribution. Proposed isolated candidate budgets median <=1000 ns/call and genuine p95 <=5000 ns/call, optimized test/process RSS <=8192 KiB. A compiler/VM-dependent budget failure is reported, not silently redefined.

No synthetic two-user/40-session learning evaluation in R2.1. Its 8-mask table is a known-answer unit test, **not** a held-out learning generalization test. A/B synthetic experimental data and preregistered seeds from R2.0 are reserved for R2.2–R2.3 after another freeze.
