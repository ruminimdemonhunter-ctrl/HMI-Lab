## Mission (preflight only, NOT a scientific study)

Build a **finite, offline, synthetic, test-only independent utility-evaluation instrument** that proves it can:
- separate available observed history from hidden future-task truth;
- reproduce the genuine V0.1 support and fail cold/late-reset histories;
- score toy role-triple predictions against independent truth with exact known-answer arithmetic and safety violations;
- select the strongest calibrated comparator among `RECENT_N` {1,2,3,5,8}, `STATIC_WORKSPACE`, `STATIC_GLOBAL`, `ALWAYS_NONE`, without giving any candidate information not available to competitors;
- validate the full SHA256 calibration lock against actual file bytes and refuse every invalid lock **before** attempting any open of a dummy heldout path;
- preserve all L1/L2 protected model source, fixtures, RC0 tests and blocked actuation authority.

**Key distinction:** even all-green scores on these canned preflight fixtures mean the **scorer/harness was tested**, not that L2 predictions are useful. There must be no actual V0.2 large corpus, no first heldout model evaluation and no scientific utility claims.

## Future implementation stages after these frozen docs

- Build tiny deterministic synthetic known-answer training and mock calibration controls with separate future truth; no real OS events and no staged heldout scientific corpus.
- Implement independent fixture verifier for schema, event order, post-exclusion row/session eligibility, workspace support after last reset and exact A/B mixed identity/triple outputs. **Use actual V0.1 code as a separate cross-check**, not as reference truth.

**Stage 2 — scoring/comparison and lock**
- Use independent stdlib-only Python utilities (acceptable for offline scientific harness) and optionally bounded C11 reference baseline runners. Ensure every candidate sees byte-identical pre-query permitted input and no hidden truth fields.

Reject absent/edited/duplicate/unknown keys, modified legitimate file bytes, mutated chosen parameters and invalid digest. ## Explicit exclusions

No real telemetry, process/file/window/keyboard captures, hidden application contents, OS folder operations, system daemon or timer, network client, privileged commands, cgroup/scheduler control, L1 policy writes, L3/cloud layer, user profiling or Windows-host modifications. All predicted workspace layouts are **non-executable enum codes**. Only explicitly invoked finite synthetic fixtures may be read. The accepted L2 V0.1 model and original L1 protected files are read-only.

**No full V0.2 scientific study begins under this handoff.** A separate, explicitly approved and fully preregistered numerical study is required after this preflight passes independent review.
