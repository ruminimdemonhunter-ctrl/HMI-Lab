## Implemented preflight

The stdlib-only offline harness provides:

- an independent strict fixture verifier for canonical schemas, IDs, event order, completed sessions, reset boundaries, actual support, provenance, separated truth, and manifest bytes;
- executable `RECENT_N` comparators for N in `{1,2,3,5,8}` that count every contiguous three-role window inside each of the last N eligible completed sessions, plus trained `STATIC_WORKSPACE`, `STATIC_GLOBAL`, and `ALWAYS_NONE` comparators;
- the real compiled, unmodified `l2_fixture_cli` as `V01_FROZEN` and as a cross-check against the independent verifier;
- one shared query-context safety wrapper for every candidate;
- a strict prediction parser and exact integer toy-loss scorer;
- deterministic selection over the entire frozen comparator grid;
- a canonical single-occurrence SHA-256 lock that binds protected source, fixtures, tools, outputs, selected settings, and the calibration digest;
- a first-open sentinel proving invalid locks cause zero future-input open attempts.

### Post-review correction evidence

The two regressions were introduced and executed before their fixes. Against reviewed head `61edd103c6b449eac5d39d82ccd209836eb33c27`, the first run failed because removal of every `STATIC_GLOBAL` row was accepted. After repairing completeness, the second run failed because `RECENT_1` omitted a later contiguous triple. The corrected implementation then passed both controls.

Scoring now receives the expected candidate tuple independently of submitted predictions and requires the exact Cartesian product of all truth episode IDs and expected candidates before selecting any calibration suite. Unknown episode IDs, missing panels, duplicate rows, unknown candidates, and extra rows fail closed.

The test-only lock changed because bound verifier, comparator, scorer, and runner source bytes changed. It was advanced explicitly from `HMI_L2_V02A_LOCK_V1` to `HMI_L2_V02A_LOCK_V2`; V1 is now a negative control. Mock prediction SHA-256 and the calibration selection digest did not change, so the three calibration winners and toy results were not retuned.

## Limitations and verdicts

This preflight establishes that the proposed scientific instrument detects its frozen known errors. The data are deliberately small and synthetic, the loss is a toy arithmetic contract, the candidate relationships are non-executable enums, and the lock is unauthenticated. Results do not establish useful prediction, individuality, real-workflow transfer, learning benefit, resource savings, or production safety. A full V0.2 study requires a separate frozen protocol and explicit authorization.
