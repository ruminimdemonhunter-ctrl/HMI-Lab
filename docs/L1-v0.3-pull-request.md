# Pull request: Stabilize Level 1 memory and add deterministic replay experiments

## Summary

- gate bounded self-adaptation on both valid samples and monotonic elapsed time
- make unit-test failures effective under `-DNDEBUG`
- reject malformed, overflowing, and excessive benchmark counts
- add a strict versioned CRC32 state format with atomic local persistence and
  safe-default recovery
- compare fixed behavior memory with bounded adaptation on a labeled,
  deterministic synthetic trace
- measure false responses, missed responses, oscillation, detection delay,
  structure/RSS footprint, core timing, and full PSI observation overhead
- add strict build/test, NDEBUG, replay, ASan, UBSan, and leak checks in GitHub
  Actions

## Safety boundary

Level 1 remains an unprivileged recommendation engine. No L2/L3 service or
scheduler, priority, cgroup, kernel, device, firmware, QEMU, or hardware-control
write is present. `--state` is an explicit local behavior-memory file; the
default monitor does not persist it. CRC32 detects corruption but does not
authenticate an update source.

Replay results on the declared 1,240-sample trace:

| Metric | Fixed memory | Bounded adaptive |
|---|---:|---:|
| False-positive samples | 513 | 307 |
| Missed samples | 2 | 3 |
| Oscillations | 292 | 154 |
| Mean/max detection delay | 2 / 2 | 3 / 3 samples |
| Final bounded increment | 0 | 1 |
| Core structure | 88 bytes | 88 bytes |

Five-run median core cost was 3.199 ns for the fixed rule and 18.813 ns for L1.
Median full PSI observation-to-decision CPU cost was 138,617.360 ns fixed and
137,213.170 ns L1; the overlapping live ranges do not show a performance win.
Median peak live RSS was 1,408 KiB for both.

## Review limitations

The stability result is specific to a hand-authored trace whose noise pattern
exposes debounce behavior. It demonstrates a deterministic heuristic tradeoff,
not training, generalization, learned optimality, resource benefit, or user
benefit. Adaptation reduced false responses and oscillations but increased event
detection delay by one sample. Timing is VM-load-sensitive and descriptive.

State is single-writer, Linux-local, one rollback deep, and unauthenticated.
Storage power-loss guarantees depend on filesystem/platform rename and `fsync`
semantics. Do not merge until the complete report and memory format have been
reviewed. This PR does not authorize resource actuation.
