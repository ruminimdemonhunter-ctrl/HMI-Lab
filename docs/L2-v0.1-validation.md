## Implementation boundary

`l2_state.c` uses caller-owned fixed storage and no heap, clock, filesystem,
network or OS API. It stores bounded enum relationships for four opaque
workspaces, 16 nodes, 32 directed edges, 16 ordered triples and eight pending
roles. Sessions commit only at a valid matching end with at least three roles.
Counts saturate, full tables use deterministic eviction, and all support
counters age by integer halving every 16 completed eligible sessions.

The separate CLI reads one explicit, finite synthetic CSV. Its output is an
enum-only candidate or abstention. It cannot create directories, open programs,
change layouts, modify resources, approve a suggestion, persist identity, or
observe a live host. Every candidate has `approval=REQUIRED`.

## Test and fault matrix

All rows passed in the isolated Debian guest:

| Gate | Evidence |
|---|---|
| Strict C11 | GCC 14.2.0, `-std=c11 -Wall -Wextra -Wpedantic -Werror` |
| Assertions | Full suite rebuilt and passed with `-DNDEBUG` |
| Memory safety | ASan + UBSan + leak detection passed |
| Parser | Exact header/field count, canonical decimals, overflow, workspace bounds, enums, provenance, LF, whitespace and row-length negatives passed |
| State faults | Duplicate/regressed sequence, timestamp regression, UINT64 sequence exhaustion, invalid quality, wrong workspace, nested session, partial/short session and >8 roles fail closed |
| Fixed capacity | Node/edge/triple ceilings, deterministic replacement, saturation, exact 16-session aging and 100,000-row replay passed |
| Reset/restart | Full reset removes support; restart is canonical empty state |
| Query purity | Repeated query left all `L2State` bytes unchanged |
| Source boundary | Pure-core forbidden-API and identity/OS-control literal audit passed |
| Protected L1 | 104-byte `L1Core`, 208-byte shadow, actions and bytes were identical with L2 enabled/disabled |
| Historical RC0 | `make -C ../level1 rc0-qualification` completed with `RC0_QUALIFICATION_COMMANDS=PASS` |

During pre-commit development, the new parser tests caught two implementation
defects: unsigned subtraction in the bounded decimal check and acceptance of an
extra eleventh CSV field. Both were fixed and permanently regression-tested
before the qualified engine commit. No frozen data or acceptance threshold was
changed.

## Debian QEMU qualification

Environment:

```text
Linux hmi-vm 6.12.113+deb13-amd64 x86_64

```

Reproduction:

```sh
cd /home/lab/hmi/src/level2
make corpus-verify
make ci
ASAN_OPTIONS=detect_leaks=1 \
  UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1 make sanitize

```

The final optimized qualification measurement used five repetitions of
100,000 parsed-and-applied context events per repetition:

| Measurement | Result | Frozen budget | Gate |
|---|---:|---:|---|
| Median process CPU/event | 9,109.474 ns | <=50,000 ns | PASS |
| Worst repetition's individually measured p95 | 6,100 ns | <=250,000 ns | PASS |
| Process peak RSS | 3,104 KiB | <=8,192 KiB | PASS |
| `sizeof(L2State)` | 840 bytes | <=8,192 bytes | PASS |

Timing uses `CLOCK_PROCESS_CPUTIME_ID`. Per-event values include CSV formatting,
strict parsing and `l2_step`; individual measurements also include two clock
reads, so they are conservative and timer-overhead-sensitive. RSS is for the
whole benchmark process, not the embedded state. The synthetic fixture CLI is
not a real workload observer.

The complete Level 1 qualification also preserved historical source identities,
replay checksums, state migration, policy-security behavior and prior scientific
results. No Level 1 source file changed in this branch.

## Limitations and verdicts

The A/B difference is constructed by different synthetic histories and proves
only that the bounded representation is history-dependent and deterministic.
There is no independent user-conditioned suitability truth, fixed/recent-history
scientific comparator, real-workflow observation, persistence assessment or
benefit/harm measurement. The role enum vocabulary and simple frequency rule
may not transfer to real activity. V0.1 grants no monitoring or action authority.
