## 1. Why a research reset matters

R2.3 proved the rarity scorer *runs* but the study was INVALID due to pre-fault declared episode eligibility. Its descriptive result was worse than a strong tuned fixed comparator on both machines. No valid formal utility result exists. R2.3b must not patch those exposed held-out datasets and assert a clean replication.

R2.3b instead evaluates a narrower, meaningful low-level intelligence ability:

> **Relative to the operational pressure pattern this machine has experienced, is the current observation novel?**

This is only an observation report, not a fault diagnosis or decision to change the OS. The new test gives both machines identical probe pressure sequences but supplies independent synthetic truth for which profile normally generates that sequence. A correct response requires using each machine's accumulated operational reference.

The intended total HMI organism spans L1 sensory/reflex, future L2 machine/workflow context, and future L3 long-term personal initiative. This L1 proof does not by itself create personality.

## 5. Explicit stop conditions

- Corpus error after freeze, mismatch in any expected episode's **actual eligible rows**, invalid contextual probe pair, duplicate row IDs, data leakage: `R2_3B_STUDY=INVALID`. Do not `--force` continue.
- Insufficient independent scoreable episodes: `R2_UTILITY=INSUFFICIENT_SUPPORT`.
- Valid results but learned scorer worse than fair tuned static reference on either A or B, or lacks any sufficient family win: `R2_UTILITY=NO_GO`.
- Correct A/B probe divergence but utility failure: `R2_INDIVIDUALITY=NO_GO/UNDETERMINED`, **not GO**.
- Action or core state change, memory > budget, broken protected source identities or a new production authority path: `R2_3B_ENGINEERING=NO_GO`, stop.
- For any other scientifically ambiguous result, use `UNDETERMINED`, show why, and preserve the raw reports.

**Architectural conclusion:** a successful R2.3b would demonstrate a *limited synthetic form of machine-condition contextualization*. Real machine individuality, user learning, independent initiative and a living-like HMI remain future L2/L3 goals, not R2.3b accomplishments.
